💡 Cara Kerja Pengeditan Materi

1. Edit Materi: Pilih menu di sidebar kiri (Katalog Produk, Banner, Keunggulan, Testimoni, atau Kontak).
2. Klik "Simpan Perubahan": Perubahan akan langsung tersimpan dan dapat langsung Anda lihat di browser saat membuka website.
3. Sinkronisasi ke GitHub: Buka menu Pengaturan & Sinkron, lalu klik "Unduh data.js". Timpa file data.js di folder proyek Anda dan lakukan git push agar perubahan langsung online ke seluruh pengunjung internet.
